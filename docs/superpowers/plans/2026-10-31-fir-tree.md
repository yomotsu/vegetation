# stylized なモミ（fir）実装計画

> 2026-10-31 追記: 実装はブラウザで見比べながら大きく変わった（羽根の板 → 枝を稜線にした左右の帯、樹高 6 m、LOD0 800 頂点未満など）。確定内容は `docs/superpowers/specs/2026-10-24-vegetation-design.md` の「stylized なモミ fir」が正本。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 参考モデル（Sketchfab「Stylized Fir」）の葉を再現した stylized なモミ `FirTreeMesh` を、既存の stylized な木と同じ仕組みで追加する。

**Architecture:** 羽根形の板（中軸で V 字に折れて先が垂れる、1 枚 ≤ 8 頂点）を幹に沿って螺旋状に多数並べ、とがった円錐にする。羽根の絵（赤茶の中軸・小枝・櫛状の針葉）は新しい CPU テクスチャで描き、色変更では緑の画素だけを塗り直す（旧モミの `tree-leaf` と同じ `colorizesTexture` + `registerTextureRegenerator` 方式）。幹・LOD3/4・コライダは pine と同じ共通部品。

**Tech Stack:** TypeScript、three.js、vitest、Vite デモ

**Spec:** `docs/superpowers/specs/2026-10-31-fir-tree-design.md`

## Global Constraints

- コードスタイル: タブ、単一引用符、`if ( x ) {` の空白、ブロックの前後に空行（既存ファイルに合わせる）。コメントは日本語
- 半透明なし（alpha test のみ）。テクスチャは 2 のべき乗。alpha は 0 / 255 の 2 値
- LOD0 の頂点数 ≤ 1000。LOD1 < LOD0 × 0.65、LOD2 < LOD1 × 0.75（`tests/core/stylizedTrees.test.ts` の共通テスト）
- LOD1/2 は LOD0 と乱数の並びをそろえる。描かない部品も乱数は同じだけ引く。高さ合わせの倍率は LOD0 から求めて全 LOD に掛ける
- `src/core/trees/fir.ts` は他の種類のモジュール（pine / broadleaf / bush / willow / generators/tree）を import しない。共通は `stylized.ts` / `stylizedTextures.ts` / `leafTexture.ts` などの共有モジュールのみ
- 名前: `FirTreeMesh` / `generateFirTree` / `generateFirTreeAsync` / `generateFirTreeData` / `FirTreeOptions` / `FirTreeMeshOptions`、kind `'fir-tree'`
- 色は 1 本で 1 色。色を変えても中軸・小枝の赤茶は変わらない
- **コミットしない**: 試作はユーザーが採用するまでコミットしない（CLAUDE.md）。各タスクの最後は「テストが通る状態で作業ツリーに残す」まで

## Review Focus

1. **色変更で中軸が緑に染まる** — `leafColor` を青緑・黄緑に変えても中軸の画素は既定色のときと同じ値であること（Task 2 のテスト）
2. **seed によって頂点上限を超える／高さを超える** — seed 1〜20 のすべてで LOD0 ≤ 1000 頂点、最高点 < height × 1.02（Task 3 のテスト）
3. **極端な高さ** — height 2 と 30 でも妥当なメッシュ（`validateMeshData`）で bounds.height が一致（Task 3 のテスト）
4. **羽根が上を向く・垂れない** — 頂上の房以外の羽根は、先端が付け根より低いこと（Task 3 のテスト）
5. **Worker 経由と同期で結果が違う** — `fir-tree` の Worker 生成が同期生成とテクスチャ・頂点で一致すること（Task 4 で既存の worker テスト表に追加）

- Produces:

  - `export const FIR_FROND_MIDRIB_COLOR = 0x8a4630;`（中軸・小枝の赤茶。色変更しない）
  - `export function createFirFrondTextures( seed: number, color: number ): { color: TextureData; normal: TextureData }` — `color.colorFactors` と `color.colorPixelIndices`（針葉の画素だけ）を持つ。CPU ミップ（`textureMipmaps.ts`）は既存の葉テクスチャと同じ扱い
  - `export function composeFirFrondTexture( texture: TextureData, color: number ): TextureData` — `colorPixelIndices` の画素だけ `color` で塗り直す（`leafTexture.ts` の `composeFirSprigTexture` と同じ考え方。オフセット方式をそのまま使ってよい）

絵の要件（参考モデルの葉）: 中軸は付け根で太く先へ細る赤茶の線。中軸から左右に斜め前へ小枝（左右 6〜9 本、先ほど短い）、小枝も赤茶の細い軸。小枝と中軸の先端部に、先のとがった太めの針葉を櫛状に並べる（手描き調で 1 本ずつ輪郭が見える太さ）。全体の輪郭は付け根が細く中ほどが最も幅広い羽根形で、四辺の縁は透明。針葉の明るさは付け根で暗く先端ほど明るい（`colorFactors` に入れる）。法線は針葉ごとに丸みを付ける。

作りの要件:

- 頂上: 上向きの小さな羽根 3〜4 枚の房
- 葉の法線は円錐の外向き（板の向きではない）＋少し上向き。頂点色で樹冠の内側（幹に近い付け根）を暗く

- LOD1/2: 羽根の枚数を減らして 1 枚を大きくし、覆う量を保つ。幹の分割も落とす
- LOD3/4: `buildStylizedImpostorLods( lod0, height, height * 0.55 )`
